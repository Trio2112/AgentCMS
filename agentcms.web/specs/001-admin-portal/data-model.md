# Data Model: AgentCMS Admin Portal

**Feature**: AgentCMS Admin Portal  
**Date**: February 13, 2026  
**Purpose**: Define entity structures, validation rules, and relationships for admin portal

**Scope Note**: Pages use simple `isPublished` boolean (no publishedDate field). Assets are independent (no page-asset associations).

## Entity Overview

The admin portal manages three core entities: **Sites**, **Pages**, and **Assets**. These entities are stored and managed by the backend API; the frontend consumes them via REST endpoints.

### Entity Relationship Diagram

```
Site (1) ───────< (N) Page

Site (1) ───────< (N) Asset
```

**Relationships**:
- One Site contains many Pages
- One Site contains many Assets  
- Pages and Assets are independent (no associations)

---

## Site Entity

**Purpose**: Logical grouping for pages and assets. Represents a distinct website or content collection.

### Fields

| Field | Type | Required | Validation | Description |
|-------|------|----------|------------|-------------|
| `id` | UUID | Yes (auto) | Read-only | Unique identifier, generated by API |
| `name` | String | Yes | 1-255 chars | Display name of the site |
| `description` | String | No | 0-255 chars | Optional description/notes |

### Validation Rules

- **FR-018**: `name` is required before save
- **name**: Must not be empty or whitespace-only
- **name**: Maximum 255 characters
- **description**: Optional, maximum 255 characters

### Frontend TypeScript Type

```typescript
interface Site {
  id: string          // UUID
  name: string        // Required, 1-255 chars
  description: string | null
}
```

### Zod Validation Schema

```typescript
import { z } from 'zod'

export const siteSchema = z.object({
  name: z.string()
    .min(1, 'Site name is required')
    .max(255, 'Site name must be 255 characters or less')
    .trim(),
  description: z.string()
    .max(255, 'Description must be 255 characters or less')
    .nullable()
    .optional(),
})

export type SiteFormData = z.infer<typeof siteSchema>
```

### API Endpoints

- `GET /v1/sites` - List all sites
- `GET /v1/sites/{id}` - Get site by ID
- `POST /v1/sites` - Create new site
- `PUT /v1/sites/{id}` - Update site
- `DELETE /v1/sites/{id}` - Delete site

## Page Entity

**Purpose**: Represents a content page within a site. Can be published or draft.

### Fields

| Field | Type | Required | Validation | Description |
|-------|------|----------|------------|-------------|
| `id` | UUID | Yes (auto) | Read-only | Unique identifier, generated by API |
| `siteId` | UUID | Yes | Read-only | Parent site ID |
| `title` | String | Yes | 1-255 chars | Page title |
| `body` | String | No | 0-65535 chars | Page content (plain text or basic formatted text) |
| `isPublished` | Boolean | Yes | - | Publication status (true = published, false = draft) |
| `createdDate` | DateTime | Yes (auto) | Read-only | Timestamp when page was created |
| `updatedDate` | DateTime | Yes (auto) | Read-only | Timestamp when page was last updated |
| `createdBy` | String | Yes (auto) | Read-only | Username/ID of creator |
| `updatedBy` | String | Yes (auto) | Read-only | Username/ID of last updater |
| `lastModified` | DateTime | Yes (auto) | Read-only | Timestamp for concurrent edit detection |

### Validation Rules

- **FR-017**: `title` is required before save
- **title**: Must not be empty or whitespace-only
- **title**: Maximum 255 characters
- **body**: Optional, maximum 65535 characters (64KB)
- **isPublished**: Boolean, defaults to `false` (draft) on creation
- **Concurrent edits**: Warn user if `lastModified` changed since page was opened (FR-021, FR-022, FR-023)

### Frontend TypeScript Type

```typescript
interface Page {
  id: string                // UUID
  siteId: string            // UUID
  title: string             // Required, 1-255 chars
  body: string | null       // Optional, 0-65535 chars
  isPublished: boolean      // Required, defaults to false
  createdDate: string       // ISO 8601 datetime
  updatedDate: string       // ISO 8601 datetime
  createdBy: string         // Username or user ID
  updatedBy: string         // Username or user ID
  lastModified: string      // ISO 8601 datetime for concurrent edit detection
}
```

### Zod Validation Schema

```typescript
import { z } from 'zod'

export const pageSchema = z.object({
  title: z.string()
    .min(1, 'Page title is required')
    .max(255, 'Page title must be 255 characters or less')
    .trim(),
  body: z.string()
    .max(65535, 'Page body must be 65535 characters or less')
    .nullable()
    .optional(),
  isPublished: z.boolean()
    .default(false),
})

export type PageFormData = z.infer<typeof pageSchema>
```

### Publication State

Pages have two states:

- **Draft** (`isPublished = false`): Not visible to site visitors
- **Published** (`isPublished = true`): Visible to site visitors

Content managers toggle between states using a checkbox or toggle button.

### State Transitions

```
┌─────────┐
│  Draft  │──────┐
│(false)  │      │ Set isPublished = true
└─────────┘      │
     ▲           ▼
     │      ┌──────────┐
     │      │Published │
     │      │  (true)  │
     │      └──────────┘
     │           │
     └───────────┘
   Set isPublished = false
```

### API Endpoints

- `GET /v1/sites/{siteId}/pages` - List all pages for a site
- `GET /v1/sites/{siteId}/pages/{id}` - Get page by ID
- `POST /v1/sites/{siteId}/pages` - Create new page
- `PUT /v1/sites/{siteId}/pages/{id}` - Update page
- `DELETE /v1/sites/{siteId}/pages/{id}` - Delete page

## Asset Entity

**Purpose**: Represents an uploaded file or linked external resource. Independent of pages.

### Fields

| Field | Type | Required | Validation | Description |
|-------|------|----------|------------|-------------|
| `id` | UUID | Yes (auto) | Read-only | Unique identifier, generated by API |
| `siteId` | UUID | Yes | Read-only | Parent site ID |
| `filename` | String | Yes | 1-255 chars | Original filename |
| `mimeType` | String | Yes | Valid MIME | Detected MIME type (e.g., `image/jpeg`) |
| `url` | String | Yes | Valid URL | Storage URL or external URL |
| `createdDate` | DateTime | Yes (auto) | Read-only | Timestamp when asset was created |
| `createdBy` | String | Yes (auto) | Read-only | Username/ID of creator |

### Validation Rules

- **FR-019**: Validate file size and MIME type before upload
- **FR-020**: Reject files exceeding size limits or unsupported MIME types immediately
- **File size**: Maximum 10MB (configurable via `VITE_MAX_FILE_SIZE_MB`)
- **Allowed MIME types**: `image/jpeg`, `image/png`, `image/gif`, `application/pdf`, `text/html`
- **filename**: Maximum 255 characters
- **url**: Must be valid URL (HTTP/HTTPS for external, or storage URL for uploaded files)

### Frontend TypeScript Type

```typescript
interface Asset {
  id: string           // UUID
  siteId: string       // UUID
  filename: string     // 1-255 chars
  mimeType: string     // Valid MIME type
  url: string          // Valid URL
  createdDate: string  // ISO 8601 datetime
  createdBy: string    // Username or user ID
}
```

### Zod Validation Schema

```typescript
import { z } from 'zod'

const MAX_FILE_SIZE_MB = 10
const ALLOWED_MIME_TYPES = [
  'image/jpeg',
  'image/png',
  'image/gif',
  'application/pdf',
  'text/html',
] as const

export const assetFileSchema = z.object({
  file: z
    .instanceof(File)
    .refine(
      (file) => file.size <= MAX_FILE_SIZE_MB * 1024 * 1024,
      `File size must be less than ${MAX_FILE_SIZE_MB}MB`
    )
    .refine(
      (file) => ALLOWED_MIME_TYPES.includes(file.type as any),
      `File type not supported. Allowed: ${ALLOWED_MIME_TYPES.join(', ')}`
    ),
})

export const assetUrlSchema = z.object({
  url: z.string()
    .url('Must be a valid URL')
    .regex(/^https?:\/\//, 'URL must start with http:// or https://'),
})

export type AssetFileData = z.infer<typeof assetFileSchema>
export type AssetUrlData = z.infer<typeof assetUrlSchema>
```

### Asset Types

1. **Uploaded File**: File selected via file picker or drag-drop
   - Uploaded to backend storage
   - `mimeType` detected from file
   - `url` is storage URL returned by API

2. **External URL**: URL provided by user
   - Not uploaded, just linked
   - `mimeType` may need to be inferred or specified
   - `url` is the external URL

### API Endpoints

- `GET /v1/sites/{siteId}/assets` - List all assets for a site
- `GET /v1/sites/{siteId}/assets/{id}` - Get asset by ID
- `POST /v1/sites/{siteId}/assets` - Create asset from uploaded file (multipart/form-data)
- `POST /v1/sites/{siteId}/assets/from-url` - Create asset from external URL (JSON)
- `DELETE /v1/sites/{siteId}/assets/{id}` - Delete asset

## Data Model Summary

| Entity | Key Fields | Relationships | Validation Rules |
|--------|-----------|---------------|------------------|
| **Site** | id, name, description | 1:N with Pages, 1:N with Assets | name required, 1-255 chars |
| **Page** | id, siteId, title, body, isPublished | N:1 with Site | title required, 1-255 chars; isPublished boolean |
| **Asset** | id, siteId, filename, mimeType, url | N:1 with Site | filename required; file size ≤10MB; allowed MIME types only |

### Removed from Scope

- **publishedDate field**: Pages use simple `isPublished` boolean instead
- **Page-Asset associations**: Assets are independent; no many-to-many relationship
- **Scheduled publishing**: No date-based logic for future publication

## Utility Functions

```typescript
// src/lib/format.ts

export function formatFileSize(bytes: number): string {
  if (bytes === 0) return '0 Bytes'
  const k = 1024
  const sizes = ['Bytes', 'KB', 'MB', 'GB']
  const i = Math.floor(Math.log(bytes) / Math.log(k))
  return Math.round(bytes / Math.pow(k, i) * 100) / 100 + ' ' + sizes[i]
}

export function formatDate(isoString: string): string {
  return new Date(isoString).toLocaleDateString('en-US', {
    year: 'numeric',
    month: 'short',
    day: 'numeric',
    hour: '2-digit',
    minute: '2-digit',
  })
}

export function getPublicationStatusLabel(isPublished: boolean): string {
  return isPublished ? 'Published' : 'Draft'
}

export function getPublicationStatusBadgeColor(isPublished: boolean): string {
  return isPublished ? 'green' : 'grey'
}
```

## Notes

- All entities use UUIDs for `id` fields
- All timestamps are ISO 8601 format (`YYYY-MM-DDTHH:mm:ss.sssZ`)
- All string lengths are measured in characters, not bytes
- Frontend validation is UX enhancement; backend validates all mutations
- `lastModified` timestamp enables concurrent edit detection without pessimistic locking
